# Dartmoor.uk

Independent visitor guide and tourism website for Dartmoor National Park.

Built with Next.js (App Router) and Tailwind CSS. Deployed on Vercel.

## Local Development

```bash
npm install
npm run dev
```

## Features

- Responsive design
- Attractions, walks and practical information
- Mobile-friendly navigation
- Optimised for SEO and fast loading

Domain: dartmoor.uk
